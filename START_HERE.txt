FITBOOK FINAL

1. Установить Node.js 20+.
2. В папке проекта выполнить npm install.
3. Создать .env по примеру .env.example.
4. Для локального запуска указать URL и publishable key проекта Supabase fitbook-final.
5. Выполнить npm start.
6. Открыть http://localhost:3000.

На учебном компьютере Windows при блокировке npm.ps1 используйте:
npm.cmd install
npm.cmd start

В проекте реализованы пользовательское недельное расписание, записи, история статусов, административная панель и два статистических графика.
