# Проверка лабораторной FitBook

## База и связи

- [x] PostgreSQL в Supabase.
- [x] 5 прикладных таблиц.
- [x] Первичные и внешние ключи.
- [x] Связи 1:N.
- [x] RLS на всех прикладных таблицах.
- [x] ER-описание соответствует фактической структуре.

## Авторизация и роли

- [x] Supabase Auth.
- [x] Регистрация и вход.
- [x] Роли `user` и `admin`.
- [x] Обычный пользователь не видит административные разделы.
- [x] Администратор получает отдельную навигацию и операции.

## Новые функции

1. История изменения статусов через отдельную таблицу `booking_status_history`.
2. Недельное расписание Пн-Вс с переключением недель.
3. Фильтрация расписания по направлению, тренеру и уровню.
4. Ограничение количества мест.
5. Контроль пересекающихся временных интервалов.

Требование минимум трёх функций выполнено. Дополнительная таблица используется функцией истории статусов.

## Бизнес-правила

- [x] Нельзя записаться сверх вместимости.
- [x] Нельзя создать повторную активную запись на то же занятие.
- [x] Нельзя записаться на пересекающееся время.
- [x] Нельзя записаться на прошедшее или отменённое занятие.
- [x] Пользовательская отмена ограничена правилом двух часов.
- [x] Критичные правила проверяются на уровне PostgreSQL RPC, а не только кнопками интерфейса.

## Административная панель

- [x] Средняя заполненность.
