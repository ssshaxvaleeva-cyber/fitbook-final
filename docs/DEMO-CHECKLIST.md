# Чек-лист демонстрации FitBook

## Пользователь

- [ ] Войти или зарегистрироваться.
- [ ] Показать недельное расписание Пн-Вс.
- [ ] Переключить неделю.
- [ ] Показать фильтры по направлению, тренеру и уровню.
- [ ] Записаться на доступное занятие.
- [ ] Открыть «Мои записи».
- [ ] Показать карточку записи и историю статусов.
- [ ] Показать блокировку повторной или конфликтующей записи.

## Администратор

- [ ] Открыть страницу «Обзор».
- [ ] Показать минимум четыре KPI.
- [ ] Переключить период 7/30/всё время.
- [ ] Показать график «Записи по направлениям».
- [ ] Показать график «Состояние записей».
- [ ] Добавить занятие.
- [ ] Открыть участников занятия.
- [ ] Открыть «Все записи».
- [ ] Отметить запись как посещённую.
- [ ] Показать административную отмену.

## Безопасность

- [ ] У обычного пользователя нет административной навигации.
- [ ] Чужие записи недоступны пользователю.
- [ ] `.env` отсутствует в репозитории.
- [ ] Клиент получает только URL проекта и publishable key Supabase.
